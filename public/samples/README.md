# תמונות דוגמה

שני קבצים שמאכלסים את כרטיס ההדגמה כשאין ללקוח תמונות משלו.

| קובץ | תפקיד | יחס מומלץ |
|---|---|---|
| `logo-example.jpg` | הדיוקן/לוגו בכרטיס לדוגמה, ומילוי ברירת מחדל כשאין לוגו | ריבוע, 400×400 ומעלה |
| `cover-example.jpg` | תמונת הקאבר בכרטיס לדוגמה | רחב, 1600×900 ומעלה |

## חשוב לפני שמעלים

**זכויות שימוש.** בתמונה של אדם מזוהה נדרשת הסכמה לשימוש מסחרי בדמות
(זכות הדמות לפי חוק הגנת הפרטיות). בתמונת נוף או צילום מסחרי נדרש רישיון
שמתיר שימוש מסחרי. אלה תמונות שמופיעות בדף השיווקי, ולכן זה שימוש מסחרי
לכל דבר.

**גודל.** כדאי לדחוס מתחת ל-300KB לקובץ. הן נטענות בכל כניסה לכרטיס
ההדגמה ומשפיעות ישירות על מהירות דף הנחיתה.

## מה קורה אם הקבצים חסרים

שום דבר נשבר. `CardPreview` נופל אוטומטית לרקע הגרדיאנט ולראשי התיבות,
בדיוק כמו היום. אפשר להוסיף אותם מתי שנוח.
