# תמונות דוגמה

מאכלסות את כרטיס ההדגמה (`/noa-design`) ואת התצוגה בדף הנחיתה.

| קובץ | תפקיד | מידות |
|---|---|---|
| `logo-example.jpg` | דיוקן/אווטאר בכרטיס ההדגמה | 512×512 · 17KB |
| `cover-example.jpg` | תמונת הקאבר | 1600×900 · 174KB |

## הן משמשות את כרטיס ההדגמה בלבד

התמונות **אינן** ברירת מחדל לכרטיסים של לקוחות. כרטיס לקוח ללא לוגו
ממשיך להציג את ראשי התיבות והגרדיאנט. הצבת תמונה של אדם מזוהה בכרטיס
של לקוח אחר היא שימוש בדמות ללא הסכמה — ובנוסף מבלבלת את מבקרי הכרטיס.

## הוספה או החלפה

```bash
node scripts/optimize-samples.mjs <קובץ-לוגו> <קובץ-קאבר>
```

הסקריפט חותך את הלוגו לריבוע סביב אזור העניין בתמונה (בדרך כלל הפנים),
מקטין את הקאבר ל-1600×900 ומדחס את שניהם. אין להעלות קבצים גולמיים —
המקוריות כאן שקלו 1.1MB יחד, וכל מבקר בדף הנחיתה היה מוריד אותן.

## זכויות

בתמונה של אדם מזוהה נדרשת הסכמה לשימוש מסחרי בדמות, לפי חוק הגנת
הפרטיות. בצילום מסחרי נדרש רישיון המתיר שימוש מסחרי. אלה תמונות בדף
שיווקי, ולכן זהו שימוש מסחרי לכל דבר.

## אם הקבצים נמחקים

שום דבר לא נשבר. `SafeImage` נופל אוטומטית לרקע הגרדיאנט ולראשי התיבות.
