## הסטאק שאומת בפועל

| רכיב | גרסה | הערה |
|-------|-------|-------|
| Next.js | 16.3.4 | App Router, Turbopack. `proxy.ts` ולא `middleware.ts` |
| React | 19.2.8 | Server Actions + `useActionState` |
| TypeScript | 5.x | `strict: true`, אין `any` בקוד המערכת |
| Tailwind | 4.x | `@tailwindcss/postcss` |
| Supabase | `@supabase/ssr` 0.12.6, `supabase-js` 2.115.0 | **לא מחובר לפרויקט** |
| zod | 4.5.4 | סכמות משותפות לשרת וללקוח |
| ניהול חבילות | npm + `package-lock.json` | |
| ספריית אייקונים | `lucide-react` 1.41.0 | |

**החלטות ארכיטקטורה שנשמרו במכוון:**

- **לא הוספתי React Hook Form.** התשתית הקיימת היא Server Actions + `useActionState` + zod, והיא עובדת. הוספת RHF הייתה יוצרת מערכת טפסים מתחרה — בניגוד לדרישה המפורשת.
- **לא הוספתי Playwright.** קיימות שתי חליפות בדיקה ב-Node ללא תלויות (`e2e-check`, `flow-check`), ויחידה שלישית ב-`node:test`. Playwright מוריד דפדפנים ומוסיף ~300MB. מסומן כנדחה, ראו למטה.
